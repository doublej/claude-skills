# 01-existing-tools — Tool Inventory

Map of the Dutch tax and bookkeeping ecosystem: MCP servers, open-source libraries, and SaaS platforms you can integrate with or learn from.

## Contents

Three sibling files in this folder:

1. **mcp-servers.md** — Moneybird, Exact Online (CData), Belastbaar, OmniZoek, SmartLedger. Protocol specifications, maturity, read/write split, when to use each.

2. **repos.md** — 18 open-source projects grouped by function: classification skills, receipt extraction, API wrappers, tax calculators, case studies. Licenses, language, status.

3. **platforms.md** — 16 commercial/SaaS platforms: Moneybird, e-Boekhouden, Exact Online, Jortt, Yuki, AFAS, SnelStart, Twinfield, Rompslomp, Boekie AI, Paperdork, BTW Vriend, Fiscaal Agent, GekkoBot, ZZP Pulse, BTWmate. Official URLs, API surface, NL focus, AI integration claims, recommendation for ZZP vs BV.

## When to load this folder

Load this folder when:

- User asks "Which MCP server connects to Moneybird / Exact Online / e-Boekhouden?"
- User asks "What open-source tools are there for Dutch bookkeeping?"
- User asks "Can I integrate with my bookkeeping platform?"
- User asks "What platforms do ZZP accountants actually use?"
- User wants to understand the ecosystem before building/integrating
- User is evaluating whether to build custom vs. buy/integrate
- User asks about existing repos or case studies for Dutch tax automation
